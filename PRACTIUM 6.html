CSS Positioning in Action

The five position values below are the same techniques used across this portal: a sticky header, badges on job cards, and floating Apply / Back-to-top buttons. Scroll the page and the grey boxes to see each one behave.

1. Static

position: static; is the default. Elements follow the normal document flow and top / left are ignored.

Static box
Next element (flows below)

2. Relative

position: relative; top: 12px; left: 30px; shifts the box from its normal spot, but its original space stays reserved.

Relative box (shifted)
Next element (did not move up)

3. Absolute

position: absolute; top: 10px; right: 10px; removes the box from the flow and places it inside the nearest positioned parent.

Absolute tag
Parent is position: relative

4. Fixed

position: fixed; bottom: 24px; right: 24px; pins an element to the browser window. It stays put while scrolling.

Look at the floating Apply Now and ↑ buttons at the bottom-right corner of the screen.

5. Sticky

position: sticky; top: 0; acts like relative until the scroll offset is reached, then sticks. Scroll inside this box.
